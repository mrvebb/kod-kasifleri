# Kod Kaşifleri

İlkokul öğrencileri (8-10 yaş) için oyunlarla algoritmik düşünme, kodlama ve mantık kapıları eğitimi.
Selçuk Üniversitesi Bilgisayar Mühendisliği · Topluma Hizmet Uygulamaları dersi projesi.

**Oyna:** https://mrvebb.github.io/kod-kasifleri/

## Oyunlar

| Bölüm | Oyun | Kazanım |
|---|---|---|
| Algoritma Adası | Hazine Avı (12 bölüm) | Sıralama, algoritma, döngü |
| | Kod Rallisi (8 yarış) | Göreli yön (araca göre sağ/sol), en kısa yol, verimli algoritma |
| | Hata Avcısı | Hata ayıklama |
| | Robot Aşçı | Adım sırası (bilgisayarsız da oynanabilir) |
| | Örüntü Bulmaca | Örüntü tanıma |
| Mantık Atölyesi | Lambayı Yak | VE, VEYA, DEĞİL kapıları |
| | Kapı Bekçisi | Mantığı günlük hayatla ilişkilendirme |
| | Devre Ustası | Doğruluk tablosu |
| Kamera Laboratuvarı | Kartlarla Kodlama | Renkli kartlarla somut kodlama, görüntü işleme |
| | Renk Avı | Renk algılama |
| | Hareketle Yönlendir | Hareket algılama |

Renk kartları: yeşil ↑, kırmızı ↓, mavi ←, sarı →.

## Kullanım

- Kurulum gerekmez. `index.html` dosyasını Chrome ile açın ya da GitHub Pages bağlantısını kullanın.
- Tek dosyadır, internet olmadan da çalışır (yazı tipleri internet yoksa sistem yazı tipine döner).
- Akıllı tahta, dokunmatik ekran, fare ve klavye (ok tuşları) ile kullanılabilir.

## Gizlilik

Kamera görüntüsü yalnızca cihazda anlık işlenir; kaydedilmez ve hiçbir yere gönderilmez.
Öğrenciden kişisel veri alınmaz. Yıldızlar yalnızca o tarayıcıda saklanır.

## Teknoloji

HTML5, CSS, JavaScript (kütüphanesiz). Görüntü işleme: canvas üzerinde HSV renk sınıflandırma ve kare farkıyla hareket algılama.
